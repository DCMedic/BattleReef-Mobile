# BattleReef Mobile Delivery Roadmap

## Foundation 0.1 — complete in this milestone

- SDK 57 TypeScript project and branded navigation
- Offline SQLite schema and versioned migration
- Multiple aquarium development model
- Aquarium creation
- Manual water-parameter logging
- Maintenance task creation and completion
- Dashboard, logbook, tasks, and product-boundary screens
- Product requirements and architecture guardrails

## Foundation 0.2 — next

- Edit/delete flows with confirmation and undo where practical
- Robust domain validation and repository tests
- Aquarium edit/archive workflow
- Target ranges by aquarium type with non-color status labels
- Charts for parameter history
- Date/time picker for maintenance tasks
- Error boundary, database recovery messaging, and production logging policy

## MVP 0.3–0.6

- Onboarding and guided aquarium setup
- Recurring tasks and local notifications
- Livestock inventory, equipment inventory, observations, and photos
- Unified aquarium timeline and search
- Import/export plus encrypted local backup/restore
- Accessibility hardening and localization readiness
- Basic entitlement boundary and transparent Pro preview

## Release candidate 0.7+

- Privacy disclosures, terms, support, and in-app feedback
- Telemetry limited to consented product health metrics
- Performance, migration, offline, accessibility, and security testing
- Store assets, signing, internal distribution, beta feedback, and remediation
- App Store and Google Play submission readiness

## Post-launch

- Optional account and encrypted cloud sync
- Advanced analytics and reports
- Collaboration
- Siri, Alexa, and Google informational/logging/reminder integrations
- BRMC and Matter-compatible control only after hardware enters active production
